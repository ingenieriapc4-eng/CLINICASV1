MEDICAMENTOS - CLINICA
====================

Esta carpeta está reservada para la base de referencia de medicamentos de la clínica.

Recomendación:
- Utilizar una fuente farmacológica validada y con fecha/versión.
- No introducir dosis o indicaciones sin verificar la fuente.
- Mantener principio activo, presentación, vía, advertencias, contraindicaciones,
  interacciones y fecha de actualización.
- La información del vademécum es de referencia; la decisión clínica corresponde
  al profesional tratante.

La aplicación V5 deja preparada la interfaz para integrar esta información con la receta.
No se incluyen dosis automáticas en esta versión inicial.
